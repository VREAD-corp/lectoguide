# Candide, ou l’Optimisme (Voltaire), source

- Page : https://fr.wikisource.org/wiki/Candide,_ou_l%E2%80%99Optimisme/Garnier_1877 (une sous-page par chapitre : `Candide, ou l’Optimisme/Garnier 1877/Chapitre 1` à `Chapitre 30`).
- Édition transcrite : Œuvres complètes de Voltaire, édition Louis Moland, Paris, Garnier frères, 1877, tome 21 (fac-similé Livre:Voltaire - Œuvres complètes Garnier tome21.djvu). Texte « validé » sur Wikisource. Première publication du conte : janvier 1759, Genève (notice Wikisource).
- Version du texte : Moland suit le texte revu par Voltaire. Une note de l’édition indique que le chapitre XXII « a été beaucoup augmenté en 1761 » et donne en note la leçon de 1759 ; une autre note (chapitre XV) signale que « Croust » remplace « Didrie » des premières éditions. Le texte des unités est donc celui de l’édition Moland (avec les ajouts de 1761), pas l’édition originale de 1759.
- Licence : transcription Wikisource sous CC BY-SA 4.0 ; le texte de Voltaire (mort en 1778) est dans le domaine public.
- Récupération : API Wikisource `action=parse` (prop=text), 17 octobre 2026 ; HTML nettoyé (en-tête, navigation et numéros de page supprimés). Toutes les notes de bas de page et leurs appels ont été retirés : ce sont des notes d’éditeurs (Beuchot, Kehl, Avenel, Decroix, Moland), sauf une note du chapitre XI attribuée à Voltaire, que l’édition dit posthume et absente des éditions de Kehl ; elle n’est pas reproduite.
- Découpage : les 30 chapitres de l’auteur, un fichier par chapitre ; chaque fichier commence par le numéro et le titre du chapitre tels que l’édition les donne. « FIN DE CANDIDE. » est conservé à la fin de 30.txt. La page de titre (« traduit de l’allemand de M. le docteur Ralph… ») n’est pas reprise dans les unités.
- Espaces insécables (U+00A0) conservées comme dans la transcription. Aucune modification du texte de l’auteur.
